## 2. Developer Certificate of Origin (DCO) Sign-off
To ensure that you have the legal right to submit your code and that you agree to the terms above, **all commits must be signed off**.

* **Web-based commits:** If you edit files directly on GitHub, the repository settings will prompt you to sign off automatically.
* **Command-line (Git CLI):** If you are pushing from your local machine, you must use the `-s` (or `--signoff`) flag when making a commit:

```bash
git commit -s -m "Add your commit message here"
```

This will automatically append the following line to your commit message, confirming your agreement:
`Signed-off-by: Your Name <your.email@example.com>`

*Pull Requests with commits that are not signed off will not be merged.*

## 3. Pull Request Process
1. Fork the repository and create your branch from `main`.
2. Ensure your code follows the existing style and architecture.
3. Test your changes locally before submitting.
4. Issue that Pull Request and include a clear description of the changes you've made.
